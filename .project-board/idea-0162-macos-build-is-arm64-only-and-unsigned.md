## Суть

`release.yml` собирает dmg только под `macos-14` (arm64) и подписывает
ad-hoc: `codesign --force --deep --sign -` (`:314–315`). Нотаризации нет, значит
на чужой машине Gatekeeper встретит сборку как «повреждённую» или «от
неизвестного разработчика». README при этом говорит просто «открыть образ и
перетащить приложение в Программы» и о Gatekeeper молчит.

На Intel-Mac сборки нет вовсе, хотя цель обещает macOS без оговорок.
