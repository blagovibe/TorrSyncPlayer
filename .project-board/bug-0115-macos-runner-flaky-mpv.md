## Суть

`Test Frontend (macos-latest)` упал на
`TestRealMpvLoadsExternalSubtitlesOverAuthenticatedHTTP` с
`player: error running command` и `[ipc_1] Write error (Broken pipe)` —
то есть mpv на раннере умер или закрыл IPC до того, как команда ушла.
Код при этом был тем же: та же джоба была зелёной на трёх предыдущих
прогонах (562b708, 99fa6ad, 695dea2) и **стала зелёной при повторе
красного прогона без единой правки**.

Проверено: mpv на macOS-раннере — 0.41.0 из brew, headless, без
дисплея; падение при старте воспроизводится не каждый раз. Linux и Windows
на том же коммите зелёные.

## Обсуждение

2026-10-17: Найдено при проверке перед релизом v0.3.1. Пока это флак
раннера, а не дефект кода: перезапуск красной джобы без правок даёт
зелёный результат. Что стоит сделать, когда дойдёт черёда: либо ждать
готовности mpv перед командой и повторять её при broken pipe, либо
пометить macOS-джобу как известно нестабильную по mpv и не путать её с
регрессией. Сейчас не трогаю: лечить симптом вслепую — худший вариант из
возможных, а карточка сохраняет знание для следующего раза.
