## Суть

Владелец (диагностика v0.4.12, 2026-11-16 23:51): добавлен The.Odyssey.2026
(файлов в торренте: 1). Нажатие на постер — «Выберите файл для воспроизведения»,
и так по кругу; фильм так и не играет. Торрент ещё и нельзя удалить
(«Играет — сначала остановите воспроизведение»), хотя в плеер ничего не ушло.

## Причина

Переход на «полку» (idea-0187) спрятал список файлов торрента для однофайловых
торрентов: панель «Фильмы» заменена нумерованными чипами в футере, а чипы
скрываются при 1 файле. `play()` всегда тянет список файлов и вызывает
`presentFiles`, который только показывает тост «выберите файл» и НЕ выбирает
его сам. Для однофайлового торрента больше не было ни одного элемента,
способного запустить воспроизведение: всё нажатие упиралось в невидимую
дверь. Строчка «Играет …» была честной только по названию: `w.current` ставился
при просмотре списка, а `removeTorrent` отказывал при любом `w.current != nil`.

## Исправление

- `obviousFile`: один файл в торренте — очевидно он; несколько видео, но одно
  крупнее остальных втрое и более — это фильм с подарками, он и играет;
  сопоставимые по размеру видео (сезон) — как раньше, выбор за человеком
  (чипы видны, тост «Выберите файл» остаётся).
- `play()` делает очевидный выбор и идёт сразу в `playFile` — тост «Выберите
  файл» больше не звучит там, где выбор очевиден; в плеер улетает `loadfile`.
- `removeTorrent` и кольцо играющего постера опираются на `ctlOn` (живой
  плеер), а не на «был ли просмотрен список файлов».
- Регрессия закрыта тестами: `TestTappingAOneFilePosterSelectsAndPlays`
  (стоячий стенд-плеер: выбирает файл → mpv получает `loadfile`),
  `TestTappingASeasonPosterWaitsForAChoice` (сезон: ничего не выбирается).

## Проверка

Локальные тесты зелёные; CI — см. коммит v0.4.13. Владелец — на живой машине:
добавьте однофайловый торрент, тапните постер: фильм должен начать играть.
