## Суть

При прожарке CONCEPT.md пользователь поставил вопрос: «почему приложение само
не может обновляться из релизов на гитхаб?» Разбор, который к этому приложился:

- релизная страница и файл живут в одном домене, поэтому `SHA256SUMS` рядом с
  бинарником защищает от повреждения при скачивании, но не от подменённого
  релиза (угнанный токен, вредоносная подмена на странице);
- железное лекарство — подпись релиза и пиннинг ключа внутри приложения; у
  проекта её нет и не появится без отдельного решения о трате (macOS/Windows
  не подписаны, `$99/год` отвергнуты при разборе подписи, см. прожарку);
- механика замены нетривиальна: Windows не отдаёт запущенный `.exe` (нужен
  хелпер и перезапуск), macOS — новый файл под Gatekeeper, Linux — замена
  AppImage и рестарт;
- бесплатные каналы обновления существуют (winget, choco, brew) и дают тот же
  пользовательский эффект без встроенного updater'а, но это соседние каналы,
  отличные от текущего «релизы на GitHub — единственный канал».

Владелец решил: не non-goal («никогда»), а кандидат на отдельное
проектирование — карточка и отдельный разговор, ничего не реализовывать сейчас.
