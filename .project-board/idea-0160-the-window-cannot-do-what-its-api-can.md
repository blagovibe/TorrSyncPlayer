## Суть

Цель рисует окно как экран, а не панель настроек, и обещает «то, что человек
настраивает раз, — в стороне». По коду ряд действий до окна не доходит, хотя
бэкенд их умеет:

- **добавить `.torrent` из файла нельзя** — поле принимает только magnet
  (`frontend/internal/ui/window.go`, `addTorrent`), а API принимает base64
  `torrentFile` (`backend/internal/api/handlers_torrent.go`,
  `models.AddTorrentRequest`);
- **удалить торрент нельзя** — `DELETE /api/v1/torrents/{id}` есть
  (`api/router.go:90`), вызова из окна нет;
- **выйти из комнаты нельзя** — `leaveRoom` вызывается только при повторном
  входе или создании (`window.go:587–590`, `:630`), отдельного действия нет;
- **«скачать целиком» нельзя** — есть только просмотр из буфера; у multiplex
  оба режима, и это первое, чего не хватает человеку с плохой сетью;
- **в списке торрентов только имя** — прогресса, скорости и размера нет в
  списке, хотя статус подготовки их показывает для играющего
  (`status.preparing`);
- **описания раздачи нет** — ни экрана, ни строки, хотя это то, что человек
  читает до старта.

Всё это — один слой окна против готового бэкенда; архитектура менять не нужно.

## Обсуждение

2026-10-23: Найдено аудитом против цели и подтверждено чтением окна, каталога
текстов и роутера. Это кандидат: какие пункты брать и в каком порядке — решение
владельца. Пункт «скачать целиком» — не только UI: ему нужен честный статус
(range уже есть) и место на диске, поэтому он идёт отдельным шагом.

2026-10-23: Решение владельца по составу (вопрос с вариантами, ответ выбран
явно): берём **добавление `.torrent` из файла**, **удаление торрента**,
**прогресс и скорость в списке**, **экран описания раздачи** и **автопоиск mpv с
подсказкой установки**. «Скачать целиком, потом смотреть» в эту итерацию не
берём — не отказ, а отложено: пункт вернётся отдельной карточкой, когда до него
дойдёт очередь. Пункт «выход из комнаты» в списке выбора не участвовал, но
остаётся в сути карточки как пробел, который надо закрыть вместе с остальными.
