## Суть

Позиция воспроизведения приходит в байтах выбранного файла
(`frontend/internal/room/buffer.go`), а `buffer.Service` переводит её в номера
кусков напрямую: `startPiece := int(BufferStart / pieceSize)` — без смещения
файла внутри торрента (`backend/internal/buffer/service.go:162–208`). Само
смещение не сохраняется и не передаётся: `RegisterTorrent` пишет
`FileIndex: 0` жёстко (`service.go:95–119`), а `GetBufferInfo` возвращает тот же
ноль (`service.go:210–239`).

Один файл — работает. Многофайловая раздача (сезон, папка) — нет: у любого
файла, кроме первого, нужные куски получают `None` или чужие `Now`, то есть
обещание «смотреть, пока качается» деградирует ровно на том кейсе, который
встречается чаще всего.

Тестов на это нет: в `backend/internal/buffer/service_test.go` нет ни `Offset`,
ни многофайлового торрента.

## Обсуждение

2026-10-23: Найдено аудитом против цели. Проверено чтением
`buffer/service.go:95–119,130–160,162–208,210–239`. Лечение: передавать
`FileIndex`/`file.Offset()` в регистрацию, прибавлять смещение при переводе
байтов в куски, отдавать настоящий `FileIndex`; тест на торренте из двух
файлов, где играет второй.
