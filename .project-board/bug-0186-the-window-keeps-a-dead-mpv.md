## Суть

Со своего ПК владельца (пакет v0.4.6, 2026-11-16T09:09:38 и 09:09:42): окно
пытается включить `.avi`-файл, `/api/v1/torrents/.../select` отвечает 200,
а плеер читает именованный канал `torrsync-14092`, которого нигде нет —
`player: open pipe torrsync-14092: The system cannot find the file specified.`

Оба несостоявшихся воспроизведения подряд падают с одной и той же ошибкой
(09:09:38, файл `JN.01.Когда атакуют штаны.avi`; 09:09:42, файл
`JN.02a.Обычный мальчик.avi`). Ни одна команда mpv не доходит.

Тот же .ac3 файл за минуту до этого воспроизводил звук и показывал позицию
— значит, канал открывался. После чего-то (в логе этого не видно) канал
исчез. Окно продолжает его использовать.

Подтверждено чтением кода: `startPlayer` проверяет только `w.mpv != nil`,
а не `w.mpv.Alive()`, поэтому труп держится в мемо между попытками.

## Обсуждение

2026-11-16: Найдено владельцем на чипе 0.4.6. Причина самой смерти mpv —
эта строка не говорит; чистой записки о том, что mpv вышел и почему, нет.
Правка: `startPlayer` проверяет `Alive()`, а не только `nil`; перед тем как
выбросить труп, пишет в диагностику причину и хвост лога самого mpv — так
следующий запуск этот факт перестанет быть просто гипотезой. Карточка
открыта до тех пор, пока свежие логи не подтвердят поведение либо не
откроют нам настоящую причину.
