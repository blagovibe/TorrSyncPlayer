# План исправления проблем

## Проблема 1: Кодировка консоли на Windows (символы вместо текста)

### Рoot cause
Go backend выводит UTF-8 текст, но Windows консоль по умолчанию использует кодировку CP866 (для русского). Это приводит к отображению знаков вопроса вместо кириллических символов.

### Решение
Добавить в `backend/cmd/server/main.go` Windows-специфичную инициализацию кодовой страницы консоли:

```go
// +build windows

package main

import "golang.org/x/sys/windows"

func init() {
    // Set console to UTF-8 mode for proper Cyrillic output on Windows
    windows.SetConsoleOutputCP(windows.CP_UTF8)
    windows.SetConsoleCP(windows.CP_UTF8)
}
```

Это будет работать только при запуске backend как консольного приложения (не embedded с -H windowsgui).

## Проблема 2: Отсутствие поддержки .torrent файлов

### Root cause
Backend реализует только метод `AddMagnet()` для добавления торрентов по magnet-ссылке. Нет метода для добавления из .torrent файлов, хотя библиотека `anacrolix/torrent` эту возможность поддерживает.

### Backend изменения

1. **`backend/internal/models/types.go`** - добавить поле `TorrentFile` в `AddTorrentRequest`:
   ```go
   type AddTorrentRequest struct {
       MagnetURI  string `json:"magnetUri,omitempty"`
       TorrentFile string `json:"torrentFile,omitempty"` // base64 encoded
   }
   ```

2. **`backend/internal/constants/constants.go`** - добавить лимит размера торрент-файла:
   ```go
   MaxTorrentFileSize int64 = 1 * 1024 * 1024 // 1MB max torrent file size
   ```

3. **`backend/internal/torrent/service.go`** - добавить метод `AddTorrent`:
   ```go
   func (s *Service) AddTorrent(ctx context.Context, torrentData io.Reader) (*models.TorrentInfo, error)
   ```

4. **`backend/internal/validation/validation.go`** - добавить валидацию base64 и размера файла

5. **`backend/internal/api/handlers_torrent.go`** - модифицировать `AddTorrent` handler:
   - Принимать либо `magnetUri`, либо `torrentFile`
   - Декодировать base64 и передавать в новый метод сервиса

### Frontend изменения

1. **`frontend/src/MainWindow.cpp`** - добавить кнопку выбора файла и диалог
2. **`frontend/src/MainWindow.h`** - объявить слот `onAddTorrentFile()`
3. **`frontend/src/networkmanager.cpp`** - добавить метод `addTorrentFile()`
4. **`frontend/src/networkmanager.h`** - объявить метод и сигнал
