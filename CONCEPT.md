# Концепт TorrSyncPlayer

## Зачем проект существует

TorrSyncPlayer — настольный плеер для торрентов, который снимает главную
боль жанра: ждать скачивания. Файл начинает играть, как только набрано
достаточно данных для старта, остальное докачивается на фоне.

Вторая цель — смотреть вместе. Один человек включает видео, остальные
подключаются к его «комнате» и видят тот же момент в той же секунде, без
голоса и без отдельного звонка в мессенджере.

## Основные задумки

### Смотреть, а не скачивать

Фильм запускается сразу, не дожидаясь полной загрузки. Плеер играет из
буфера: первые секунды требуют меньше данных, чем файл целиком, поэтому
просмотр начинается раньше, чем заканчивается загрузка.

Плеер сам выбирает, какие части торрента качать первыми: те, что нужны
для немедленного воспроизведения, а не лежащие в конце файла.

### Синхронные комнаты

Комната — это общий просмотр. Один участник управляет воспроизведением
(старт, пауза, перемотка), остальные следуют за ним. При перемотке и
изменении скорости приложение догоняет общий момент плавно, а не рывком,
с учётом задержки сети.

Все события комнаты ходят через сервер. Участники не соединяются напрямую
друг с другом: это одинаково работает за любым NAT, требует только
исходящие соединения и не ломается, когда кто-то «за спиной» другого
провайдера.

### Доступ без лишних хлопот

Вход по логину и паролю, пароль хранится в виде bcrypt-хэша. Комната
может быть защищена паролем — её нельзя случайно открыть кому-то в интернете.
Плеер и API защищены: ограничение частоты запросов, CSRF-защита, TLS.

### Не нужно догадываться, что происходит

Весь обмен с сервером описан в Swagger и в документации API. Метрики
Prometheus показывают, что реально происходит с сервером.

## Границы проекта

### Что входит

- Настольное приложение для Linux, macOS и Windows.
- Локальный HTTP API на Go: торренты, буфер, комнаты, синхронизация, авторизация.
- Воспроизведение видео через libmpv в окне Qt.
- Синхронизация просмотра между участниками одной комнаты.

### Что заведомо не входит

- Собственный трекер или раздача торрентов. Клиент только читает чужие раздачи.
- Прямые соединения между участниками (WebRTC). Все события идут через сервер.
- Мобильные и веб-версии. Только настольное приложение.
- DRM и расшифровка защищённого видео — плеер играет то, что отдаёт torrent.
- Торрент-клиент на телефоне или встраиваемой прошивке.
