# SyncService

Сервис синхронизации воспроизведения между хостом (master) и гостем (slave). Обеспечивает синхронное воспроизведение видео на нескольких устройствах.

## Ответственности

- Отправка sync-сообщений от master к slave
- Применение remote sync на slave с latency compensation
- Heartbeat — периодическая отправка состояния (каждую секунду)
- Подавление эхо-событий (чтобы отправленный sync не вызывал повторный)
- Безопасное воспроизведение с проверкой `readyState`

## Роли

| Роль | Поведение |
|---|---|
| **master** | Привязывается к событиям `play`/`pause`/`seeked` видео, отправляет sync, запускает heartbeat |
| **slave** | Только принимает и применяет remote sync, не отправляет |

## Ключевые методы

| Метод | Описание |
|---|---|
| `play()` | Запускает воспроизведение + отправляет sync (если master) |
| `pause()` | Ставит на паузу + отправляет sync (если master) |
| `seek(timestamp)` | Перематывает + отправляет sync (если master) |
| `applyRemoteSync(message)` | Применяет remote sync на slave с latency compensation |
| `createSnapshot()` | Создаёт снимок текущего состояния воспроизведения |
| `dispose()` | Останавливает heartbeat, очищает слушателей и обработчики |

## Latency Compensation

Для `play`, `pause`, `state` сообщений:
```
compensatedPosition = position + (Date.now() - server_ts) / 1000
```
Ограничение: 0–5 секунд. Для `seek` компенсация не применяется — переход мгновенный.

## Sync Tolerance

По умолчанию 0.5 секунд. Если разница между локальным и компенсированным временем меньше толерантности — коррекция не применяется. Настраивается через UI комнаты.

## Подавление эхо-событий

При программном вызове `play()`/`pause()`/`seek()` устанавливается флаг `suppressNextEventSync`, чтобы событие от видеоплеера не вызвало повторную отправку. Heartbeat сбрасывает флаги, если событие не произошло (например, `play()` был заблокирован браузером).

## Безопасное воспроизведение

`safePlay()` проверяет `video.readyState >= 2` (HAVE_CURRENT_DATA) перед вызовом `play()`. Если данных недостаточно — браузер автоматически воспроизведёт при появлении данных.
