# RoomPage

Экран комнаты — основной рабочий экран приложения. Содержит видеоплеер, управление торрентом, список медиафайлов, информацию о комнате.

## Ответственности

- Отображение [[VideoPlayer]] с контекстными контролами
- Управление торрент-источником (только для host)
- Список воспроизводимых медиафайлов
- Настройка sync tolerance
- Информация о комнате и пирах
- Status bar с информацией о соединении и загрузке

## Режимы отображения

### Host (canControlTorrent = true)
- Поля ввода magnet-ссылки и выбора `.torrent` файла
- Кнопки "Load Magnet", "Load File", "Change Source"
- Список медиафайлов с возможностью выбора
- Настройка sync tolerance

### Guest (canControlTorrent = false)
- Только информация о текущем источнике
- Просмотр выбранного медиафайла (без возможности смены)
- Контролы воспроизведения доступны только при наличии медиа
